# Model Service Docs

## API

- `api/MODEL_API_USAGE.md`: 面向模型广场用户的对外调用文档，说明接口、字段约束、云图传入方式和错误处理。
- `api/CLOUD_API_USAGE.md`: 面向模型广场用户的云图预测 API 调用文档，说明云图预测专用接口的输入输出格式。

## Development

- `development/MODEL_SERVICE_DEV_GUIDE.md`: 面向项目组内部同学的接手说明，包含代码入口、模型分类、30->6 聚合规则、云图优先级和扩展步骤。

## Reports

- `reports/model_prediction_record.csv`: 10 组样本 x 19 个模型的逐样本预测明细。
- `reports/model_prediction_summary.csv`: 19 个模型的汇总排序结果。
