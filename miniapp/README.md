# Miniapp

微信小程序端复用 Spring Boot 的 RESTful API，禁止直接访问 FastAPI 模型服务。

当前底部导航包括概览、模型、资讯、我的：

- 概览：API Key、钱包、调用统计、趋势与最近调用记录。
- 模型：真实模型列表、搜索、类型/状态筛选与详情。
- 资讯：新闻分类、搜索、加载更多、详情及站内通知已读操作。
- 我的：用户资料、头像、修改密码、钱包流水、API Key 与模型权益概要，以及退出登录。

## 本地联调

1. 启动 Spring Boot 后端，默认监听 `http://127.0.0.1:8080`。
2. 使用微信开发者工具导入项目根目录下的 `miniapp`。
3. 本地开发时在“详情 → 本地设置”勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。
4. 编译后在“我的”连接已有平台账号，验证个人资料、密码修改、钱包和 API 权益；修改密码会使现有 Token 失效并要求重新登录。
5. 真机或体验版必须使用已备案 HTTPS 域名并在微信公众平台配置 request 合法域名。可在开发调试时通过 `wx.setStorageSync('apiBaseUrl', 'https://your-domain.example')` 覆盖默认地址，重新启动小程序后生效。

小程序不内置测试账号、Token、API Key 或业务 mock。接口返回空数组时展示真实空状态；请求失败时展示独立错误和重试入口。

## 新闻通知页面

- “新闻资讯”允许未登录访问，分类与 PC 一致：全部、气象预警、灾害动态、政策标准、行业动态、企业资讯、平台资讯。
- 搜索、分类、下拉刷新、触底分页和详情全部读取 `/api/news`；列表展示真实来源、发布时间和预警信息，不使用新闻 mock。
- 外部详情只展示后端清洗后的文本片段，并允许复制原文链接；小程序不执行爬虫、不保存外部认证信息，也不直接渲染外部 HTML。
- “站内通知”仅登录后请求 `/api/notifications`，支持全部/未读、通知类型、单条已读和全部已读。未登录时只展示登录入口，不发送通知请求。
- 请求失败、筛选无结果、首次无数据、未登录和加载中使用不同页面状态。

账户中心不提供第三方账号和人脸认证。钱包充值仅有后端本地 `MOCK` 模拟入账流程，不属于正式支付，因此小程序只展示“暂未开放”，不会发起充值或模拟支付成功。
