# 后端功能完成度与剩余工作审计

> 审计日期：2026-07-06  
> 审计范围：`backend` 当前工作区实际代码、数据库映射、接口和测试  
> 验证结果：`mvn clean test` 通过，14 个测试类、55 个测试，0 失败、0 错误

## 1. 总体结论

后端已经不再是单纯空骨架，用户认证、MyBatis 数据层、文件导入、天气 Provider、预测任务持久化、分析报告、API Key 和新闻通知等主要结构已经实现。

但目前不能判断为“全部完成”，原因主要是：

1. Python 模型服务仍使用 mock 算法，没有接入真实模型。
2. 微信、QQ 等第三方登录没有实现。
3. 人脸识别没有实现，只有预留数据表。
4. 部分管理、权限分配和数据维护接口不完整。
5. 天气 Provider 已写代码，但需要真实 Key 和联网联调验证。
6. 开放 API 限流是单机内存实现，不适合多实例部署。
7. 缺少真实 MySQL、真实天气、真实 FastAPI 的端到端测试。
8. Docker、CI、数据库迁移和生产安全配置仍未完整。

当前更准确的定位是：

```text
主要业务后端框架和多数课程项目功能已实现
        +
真实模型、可选认证能力、生产化和完整联调仍待完成
```

## 4. 用户与认证剩余功能

### 4.1 第三方登录

当前未实现：

- 微信登录。
- QQ 登录。
- GitHub 等 OAuth 登录。
- 第三方账号绑定和解绑。
- 第三方账号与已有账号合并。

已有基础：

- `sys_oauth_account` 表。
- `SysOAuthAccountDO` 和 Mapper。

建议接口：

```http
GET  /api/auth/oauth/{provider}/authorize
POST /api/auth/oauth/{provider}/callback
GET  /api/user/oauth-accounts
DELETE /api/user/oauth-accounts/{oauthId}
```

实现时必须考虑：

- OAuth state 防 CSRF。
- provider 白名单。
- openId/unionId 唯一性。
- 第三方账号首次登录时创建还是绑定本地用户。
- 第三方 Token 不能直接返回前端或明文落库。

### 4.2 人脸识别

当前未实现：

- 人脸录入。
- 人脸特征提取。

已有基础：

- `sys_face_auth` 表。
- `SysFaceAuthDO` 和 Mapper。

如果课程展示必须做人脸识别，需要先决定：

3. 是否保存原图。

## 13. 通用技术和生产化剩余工作

### 13.1 安全

- CORS 当前允许所有 Origin 且允许凭据，生产环境必须改为白名单。
- 需要明确可信代理后才能信任 `X-Forwarded-For`。
- 缺登录限流和验证码。
- 缺 Refresh Token 和 Token 撤销。
- Swagger 生产访问控制。
- 天气 Key、JWT Secret 和数据库密码需要部署密钥管理。
- Swagger 描述仍有“骨架/mock”旧文字。

### 13.2 数据库

- 目前主要依赖会 DROP 表的 `init.sql`。
- 缺 Flyway/Liquibase 增量迁移。
- 缺生产备份和恢复方案。
- 缺慢查询和索引验证。
- H2 与 MySQL 的 SQL 行为可能不同。

### 13.3 运维

- 缺 Spring Boot Actuator 健康检查。
- 缺 Dockerfile。
- Compose 中后端、前端、模型服务仍是占位构建。
- 缺 CI 自动测试。
- 缺代码覆盖率门槛。
- 缺日志追踪 ID。
- 缺接口指标和告警。

这里的可观测性是业务接口、数据库和外部服务调用，不包括已移除的服务器 CPU/GPU/内存监控模块。

### 13.4 测试

现有 55 个测试全部通过，但仍缺：

- 更多 Controller 路由和权限集成测试。
- 真实 MySQL 集成测试。
- 真实 QWeather 契约测试。
- 真实 FastAPI 契约测试。
- Web → Spring Boot → FastAPI 端到端测试。
- 大文件导入性能测试。
- 高频历史查询性能测试。
- 多用户权限越权测试。
- 开放 API 并发限流测试。

测试日志出现 Spring Security 自动生成开发密码警告，说明自动配置仍可进一步清理或显式提供认证相关 Bean。

## 16. 下一步建议

如果目标是尽快形成可演示版本，建议顺序：

```text
真实模型接入
    ↓
补一套可用电站和连续 30 分钟演示数据
    ↓
跑通登录 → 电站 → 数据 → 预测 → 报告
    ↓
真实天气联调
    ↓
前后端整体联调
    ↓
```

如果第三方登录和人脸识别是老师明确要求，则应将其提升为 P1 前置任务；如果只是预留亮点，不应影响核心预测链路交付。
